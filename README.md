# Macbook_a1706_T1_Keyboard_Backlight

T1 Backlight Control 0.2.1
Enables keyboard backlighting on Macs with a faulty T1 chip (for Windows 10).
A version for macOS will be released at a later date...

Run T1-Backlight-Control.exe.
Five buttons are available: 25%, 50%, 75%, 100%, and Off.
Brightness settings remain unchanged upon launching or closing the application.
No additional dependencies or installations are required.

This version is designed for use with the verified AppleSPIKeyboard.sys driver (version 6.1.7700.0)
and supports a backlight range of 32–512. The driver is verified before every command is executed.
The SPI path used in the previous version has been physically tested on an A1706 model equipped with a T1 chip.
